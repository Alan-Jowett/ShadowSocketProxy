Detailed Description

TC BPF packet rewriting and per-flow redirection state.

The ingress classifier creates or resolves a flow and rewrites the destination tuple toward the configured host listener. The egress classifier resolves the reverse tuple and restores the original destination. IPv4 addresses are represented as IPv4-mapped 16-byte addresses so the map ABI is shared with IPv6. Every packet access is bounds-checked for the verifier, and L3/L4 checksums are updated whenever an address or port changes. Unsupported protocols, fragments, malformed packets, and control-service traffic pass through unchanged.
