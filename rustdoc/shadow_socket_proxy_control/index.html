Control-plane library combining BPF lifecycle, configuration, maintenance, logs, ABI mapping, gRPC service, and TLS transport modules.

Modules§

bpf
BPF attachment, map, counter, and cleanup backends. Abstracts Linux TC/BPF attachment and map operations behind a testable backend, with an in-memory implementation for service and cleanup tests.
config
Runtime configuration validation and atomic publication. Validates and publishes the runtime settings shared by gRPC, maintenance, and the BPF map writer.
lifecycle
Startup, serving, maintenance, and shutdown orchestration. Owns startup, maintenance-task lifetime, transport serving, and shutdown ordering for the control service.
logs
Bounded service log ring and cursor errors. Provides a mutex-protected bounded log ring with monotonic cursors.
maintenance
Expiration scans and maintenance statistics. Scans flow-state or legacy mapping maps and removes expired entries without blocking configuration or control-service readers.
mapping
Shared tuple, flow-state, and map-ABI types. Shared tuple and flow-state model plus fixed-width, network-byte-order encoders and decoders for the control service/BPF map boundary.
proto
Generated protobuf and tonic service bindings.
service
gRPC methods and protobuf/ABI conversion helpers. gRPC control surface and conversions enforcing the protobuf/BPF ABI boundary.
transport
Linux TLS-PSK listener for the control service. Linux-only TLS 1.2 PSK listener used by the gRPC control API.
